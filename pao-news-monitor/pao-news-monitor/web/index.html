    Import items

    Excel or CSV with columns PAO (id, abbreviation or name), Date, Type (News / Event / Publication / Newsletter), Title, Content, Posted by, Link, Language. Only PAO and Title or Content are required. The Screenshots (OCR) page downloads files in exactly this format.
